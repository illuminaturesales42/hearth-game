# HEARTH — Art Generation Brief (for a chat with a reference image)

**How to use this:** Start a new chat with an image-generating assistant. **Attach your reference image** (one finished HEARTH sprite sheet or building — whatever best captures the look). Paste the **Setup message** below first. Then paste one **Batch** at a time and let it generate. Re-attach the reference image every few batches if the assistant drifts.

---

## ⭐ Setup message (paste this first, with the reference image attached)

> I'm making art for **HEARTH**, a cosy mobile merge game set in a small coastal village called Emberhollow. I've attached a **reference image** — this is the locked art style. **Match it exactly** in every image you make for me: the same hand-painted storybook look, the same warm hearth-lit colours, the same soft brushwork, the same 3/4 top-down angle, the same clean silhouettes.
>
> **Rules for everything you generate:**
> - **Transparent background** (PNG), unless I say "scene" or "banner".
> - When I ask for a **set or sheet**, lay the items out on an **even grid with big gaps between them** and lots of empty space around each — I slice them apart afterwards, so they must not touch or overlap.
> - **No text, no labels, no UI frames** anywhere in the image.
> - Keep the **lighting identical** across everything: warm gold/amber light from the upper-left, cool dusk-blue shadows.
> - **3/4 isometric** (looking down at about 30°), the same as the reference.
> - Colours to stay inside: warm gold `#f4a63b`/`#ffd27a`, deep ember `#e5761e`, parchment cream `#ecdcb6`, wood brown `#6b4a2a`, night navy `#0f1626`, sea teal `#4f8698`, leaf green `#3a5a34`. Warm and gold should dominate. Painterly, not neon, not flat.
> - Avoid: flat vector, 3D render, CGI, plastic, anime/manga, cel-shading, photos, harsh contrast, blur.
>
> I'll ask for one batch at a time. Confirm you understand the style, then wait for the first batch.

## Tips while generating

- **Go one batch at a time** and eyeball each result against the reference before moving on. If it drifts (too glossy, too flat, wrong angle), say *"more like the reference image — softer painted brushwork, warmer light, same 3/4 angle"* and regenerate.
- **Sheets must have space.** If items come out crowded or touching, say *"space them further apart with more empty background around each — I need to cut them out."*
- **Keep the light consistent.** If shadows go the wrong way, say *"light from the upper-left, warm gold, cool blue shadows."*
- For sets (avatars, chapter cards, badges), ask it to **make the first one, then match the rest to it** so the set stays consistent.

That's the full set — once these exist, HEARTH has every piece of art it needs.
